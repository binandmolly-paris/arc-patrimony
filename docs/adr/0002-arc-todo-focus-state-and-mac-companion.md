# ADR-0002: 以云端专注状态支撑跨设备规划与未来 Mac 浮窗

## Status

Accepted — 2026-08-04

## Context

ARC TODO 已有独立的家庭任务、身份与提醒模块。LIU BIN 希望同一账号可从手机、网页和电脑使用，并希望 Mac 桌面能持续显示当前最重要的一件事。纯网页无法可靠地置顶于其他 macOS 应用之上；同时，专注状态不能只存于某一台电脑的浏览器，否则手机和电脑会不同步。

## Decision

继续采用 ARC TODO 的模块化单体和 PostgreSQL 作为唯一真相源：

- 新增 `arc_todo_focus_states`，每个成员最多一条当前重点；
- 新增 `arc_todo_focus_sessions`，保存私有的开始、结束、时长及结束原因；
- 在 `/api/arc-todo/focus/*` 提供独立、会话认证的读写接口；
- 先实现网页/PWA 的日程与专注界面；后续以轻量原生 Mac companion（Tauri）读取相同 API，提供真正 always-on-top 的浮窗。

现有 `arc_todo_sessions` 继续只负责登录会话，绝不复用为专注记录。

## Consequences

### Positive

- 同一份资料可以在手机、网页和未来的 Mac 浮窗之间同步。
- 不需要新建微服务、新数据库或复制任务规则。
- 浮窗能力可原生实现，同时网页在所有设备仍可正常使用。
- 专注时长保持个人私密，管理员仅获得协作必要的当前重点名称。

### Negative

- 第一期无法让网页本身永远覆盖其他 Mac 应用；须等 companion 完成。
- 增加了专注状态的清理责任，因此任务完成时必须同步结束关联专注状态。

## Alternatives considered

### 仅用浏览器/PWA 悬浮卡

拒绝作为最终方案。它可跨设备，但无法稳定置顶于其他桌面应用。

### 新建独立桌面与后端系统

拒绝。会造成资料副本、账号分裂和额外运维，超出三人家庭的需要。

### 浏览器扩展

拒绝。仅能覆盖浏览器页面，不满足跨应用桌面提醒。
